# AddMath Mudah — KSSM Tingkatan 4 & 5 (BM / EN)

Aplikasi pembelajaran interaktif dwibahasa (**Bahasa Melayu & English DLP**) untuk pelajar Malaysia menguasai subjek **Matematik Tambahan (Additional Mathematics) Tingkatan 4 & Tingkatan 5** secara visual, menyeronokkan, dan berpandu langkah demi langkah.

## Ciri Utama
- **Dwi-Bahasa Sepenuhnya (`BM` / `EN`):** Tukar bahasa pada bila-bila masa selari dengan program DLP.
- **Enjin Kepintaran Intent & Diagnostik Sokratik:** Mengesan punca kesilapan pelajar mengikut kategori markah SPM (**Konsep `[P]`**, **Kaedah/Algebra `[K]`**, **Ketepatan/Tanda `[J]`**) dan membimbing secara langkah demi langkah (*Micro-Checkpoints*).
- **Makmal Graf Visual Interaktif (`HTML5 Canvas`):** Teroka fungsi nilai mutlak, songsang, parabola pembezalayan $\Delta = b^2 - 4ac$, persilangan tak linear, indeks/logaritma, dan penumpuan $S_\infty$.
- **Smart Solver Skema SPM:** Jana jalan kerja lengkap berlabel markah `P1`, `K1`, `J1` untuk sebarang nilai input.
- **Gamifikasi & Mesra Mudah Alih:** Sistem XP, *Combo Streak*, Misi Harian, Buku Formula 18 Bab, dan permainan pantas **Kilat Konsep 60 Saat**.
